# Icon Setup Instructions

## Icons Needed for Portfolio

The following icons need to be added to the `img/icons/` directory:

1. **zapier.png** - Zapier logo
   - Download from: https://zapier.com/brand
   - Size: 14x14px or larger (will be scaled down)
   - Format: PNG with transparent background

2. **make.png** - Make.com (formerly Integromat) logo
   - Download from: https://www.make.com/en/brand-assets
   - Size: 14x14px or larger (will be scaled down)
   - Format: PNG with transparent background

3. **chatgpt.png** - ChatGPT/OpenAI logo
   - Download from: https://openai.com/brand
   - Size: 14x14px or larger (will be scaled down)
   - Format: PNG with transparent background

4. **python.png** - Python logo
   - Download from: https://www.python.org/community/logos/
   - Size: 14x14px or larger (will be scaled down)
   - Format: PNG with transparent background

## Quick Setup

1. Download the official logos from the links above
2. Resize them to approximately 32x32px or 64x64px (they'll be scaled to 14x14px in the UI)
3. Save them as PNG files with transparent backgrounds
4. Place them in the `img/icons/` directory
5. The HTML files are already configured to use these icons with fallback to explorer.ico if not found

## Alternative: Using Web URLs

If you prefer to use web-hosted icons temporarily, you can update the image sources in `index.html` and `portfolio.html` to use direct URLs from the brand asset pages.
