Quick Steps:

  1. Visit https://frutigeraeroarchive.org/icons
  2. Navigate to the appropriate section (Windows Vista, Web Browsers, Email/Messaging, etc.)
  3. Right-click on each icon and "Save Image As..."
  4. Save to: img/icons/vista/ with the exact filename listed above
  5. If icons are in ICO format, convert to PNG (you can use online converters)
  6. Resize if needed to match the specified sizes

Note: The site will automatically fall back to Font Awesome icons if a Vista icon is missing, so you can download them gradually.
